## Help texts

### atc control

```
Usage: atc control <command>

All operations use the same validation and implementation as the terminal and web admin. Discovery works offline. Calls start the local server if needed. --json never opens a screen or prompts for missing fields.

Commands:
  list   List operation names, input schemas and effects
  call   Execute one named operation
  watch  Stream sanitized workspace state as NDJSON

Global options:
  --json                Print the result as one JSON document (errors go to stderr as JSON)
  -v, --verbose         Debug-level logging on stderr
  -q, --quiet           Only errors on stderr; no progress
  -y, --yes             Answer yes to safe confirmations; required for elevation and deletion
                        without a terminal
  --data-folder <path>  Data folder to work with (default: <system data>/atomic-chat-cli/data)
  --no-color            Disable ANSI colours (NO_COLOR is honoured too)
  -h, --help            Show help
  --version             Print the version
```
