# Open the dashboard from the final web onboarding step

- **Context:** The final step used the same Skip setup action as earlier steps. With a pending model, it showed the waiting screen even when the user wanted to leave setup.
- **Decision:** Offer Go to dashboard on the final step and finish manual setup through the existing operation. Downloads continue while the dashboard is open. The endpoint and agent choices still show the waiting screen when the chosen model is pending.
- **Owner:** team.
