# Show progress when opening terminal agent setup

- **Context:** The server overview drew a full agent card, but only its Configure label accepted a click. After that click, model and engine reads could leave the terminal looking idle.
- **Decision:** Give the card one full-surface target and show a status while the connection guide reads local model and engine choices, using the existing setup deadline.
- **Consequences:** The title and body open the same review as Configure. Loading a model and preparing a connection still requires the review action.
