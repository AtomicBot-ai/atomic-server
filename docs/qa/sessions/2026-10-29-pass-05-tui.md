# 2026-10-29 — Pass 05: TUI counterparts of the web findings

## Mission and plan

Explore terminal model selection, search, configuration and conversation recovery with an actual PTY and an isolated copy of the previous synthetic QA fixture, to discover whether the web findings have independent terminal counterparts.

- Back/forward after a non-default first-model selection, including installed versus downloadable choices.
- Catalog display-title searches with GGUF and MLX filters; empty results, refresh and format transitions.
- Real local model and engine selection, failed load and recovery, with durable selection checked separately from on-screen intent.
- Invalid API prefix and engine setting values; dirty form retention and cancellation.
- Conversation drafts, search and history after navigation, stale writes from another client and generation failure.
- Duplicate skills and history import boundaries where the TUI exposes those actions.

This is discovery/reproduction only. No product fixes, dependency changes, external tickets or commits are authorized by this pass. Original reports are retained and new confirmed defects receive IDs from B14 onward.
